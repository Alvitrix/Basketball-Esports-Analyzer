# Basketball & Esports Performance Analyzer

A beginner Python analytics tool that evaluates player efficiency in basketball and match impact in competitive esports.

## What It Does
* **Basketball Efficiency Calculator:** Evaluates points, assists, rebounds, and turnovers to rate overall court impact.
* **Esports Match Impact Scorer:** Calculates KDA ratios and objective contributions to measure team performance.

## Future Improvements
* Add interactive user input so players can enter live match stats.
* Build a simple AI win-probability predictor using historical match data.
